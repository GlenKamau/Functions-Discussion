1.The Loop Lifecycle: Identify the three expressions inside a for loop header: for(initialization; condition; final-expression). At exactly what point in the iteration cycle does the final-expression execute?
The threee expressions include:
a)initialization -  Runs only once before the loop begins.It is used to declare and initialize a counter variable
b)Condition - it acts as a checkpoint, it is evaluated before every single iteration.If it evaluates true, the loop continues but if it evaluates false the loop stops immediately.
c)Final-expression - evaluated after the loop body executes, but before the condition is checked for the next round
The final- expression is is executed at the very end of the current iterarion cycle, after the entire code block has finished running.
